# Descripción del proyecto 

StudySync es una plataforma digital diseñada para ayudar a los estudiantes en la organización de sus actividades académicas de manera personal y grupal. La aplicación permite gestionar horarios, tareas, reuniones, trabajos colaborativos y recordatorios importantes en un solo espacio. Además, busca apoyar el bienestar estudiantil mediante herramientas orientadas a mejorar la productividad y reducir el estrés académico. 

---

## objetivo 

Desarrollar una plataforma digital que ayude a los estudiantes a mejorar su organización académica, productividad y coordinación grupal mediante herramientas inteligentes de planificación, recordatorios y apoyo al bienestar estudiantil.

----
## Problemas que ayuda a resolver 

Muchos estudiantes presentan dificultades para organizar sus actividades académicas, recordar fechas importantes y coordinar trabajos grupales. Esto puede generar desorden, retrasos y estrés académico. StudySync busca facilitar la organización estudiantil mediante una plataforma centralizada. 

----

## Publico Objetivo 

*  Estudiantes Universitarios
*  Estudiantes de Institutos
*  Grupos académicos
*  Estudiantes que buscan mejorar su organización académica

----

## Funciones Principales 

* Organización personal de tareas y Horarios académicos 
* Coordinación de trabajos grupales entre estudiantes 
* Calendario sincronizado para reuniones y entregas importantes 
* Recordatorios automáticos antes de clase o tareas. 
* Notificaciones visibles desde la pantalla de bloqueo.
* Indicador de estudiantes conectados o disponibles
* Chat grupal para comunicación académica
* Espacio para compartir documentos y materiales de estudio.
* Seguimiento de actividades pendientes y complejas.
* Herramientas de apoyo para reducir el estrés académico.
